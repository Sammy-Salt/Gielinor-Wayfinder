# Gielinor Wayfinder

a test build is currently on the website
**Gielinor Wayfinder** is an offline-first companion and reference Progressive Web App (PWA) for **2009Scape**. It aims to make useful game information easy to find, explore, and use on desktop and mobile—even when an internet connection is unavailable.

## Project Goals

- **Prioritize 2009Scape:** Use 2009Scape data as the primary source of truth, with OSRS Wiki information as a secondary reference where appropriate.
- **Build a practical game companion:** Bring item, NPC, monster, equipment, crafting, character, and world information together in one place.
- **Make exploration easier:** Provide searchable reference pages and an interactive world map to help players find information and locations.
- **Work offline:** Make offline access a core part of the PWA experience.
- **Keep information organized and traceable:** Maintain consistent data structures, clear source provenance, and documented development practices.

## Launching the PWA

To test it. Download the zip. Copy it into a new directory in your terminal. Unzip it. Launch a server, I use 8000. Open Web browser and use something like localhost:8000/ in the address bar to open the PWA.

Gielinor Wayfinder is intended to run in a modern web browser. Once the app is published at a web address, use the steps below to open it and, where supported, add it to your device.

> **First launch:** Open the app while connected to the internet so the browser can download the app and its offline resources. The published site should be served over HTTPS for PWA installation and service-worker offline features to work correctly. After the initial load and caching have completed, available offline features can be used without a connection.

### Windows, macOS, and Linux (PC)

1. Open a supported modern browser, such as Chrome, Edge, or Safari (on macOS).
2. Navigate to the published Gielinor Wayfinder web address.
3. Wait for the app to finish loading while connected to the internet.
4. To install it, use the browser's **Install** option or install icon if one is offered. The location varies by browser.
5. If no install option is available, bookmark the page or keep it open in your browser.

### Android

1. Open Chrome or another supported browser.
2. Navigate to the published Gielinor Wayfinder web address while connected to the internet.
3. Wait for the app to finish loading.
4. Open the browser menu and choose **Install app** or **Add to Home screen** (the wording varies by browser and version).
5. Follow the prompts. Launch Gielinor Wayfinder later from the new home-screen icon.

### iPhone and iPad (iOS / iPadOS)

1. Open the published Gielinor Wayfinder web address in **Safari** while connected to the internet.
2. Wait for the app to finish loading.
3. Tap the **Share** button.
4. Scroll through the share options and choose **Add to Home Screen**. If offered, enable **Open as Web App**.
5. Tap **Add**. Launch Gielinor Wayfinder later from its home-screen icon.

*Installation menus and PWA support vary by browser, operating system, and version. On iOS and iPadOS, use Safari for the most consistent Add to Home Screen workflow.*

## Project Direction

Gielinor Wayfinder is being developed around the needs and data of 2009Scape rather than treating Old School RuneScape data as interchangeable. The long-term aim is a dependable, mobile-friendly, offline reference tool that makes the world and its game systems easier to understand and navigate.

## Status

This project is under active development. Features, data coverage, and platform behavior may change as development continues.
