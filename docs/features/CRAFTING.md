# Crafting & Production — PASS31.19

The offline recipe browser combines the PASS31.9 Wiki-secondary snapshot with authoritative 2009Scape Smithing and production data. The current primary data includes 167 generated Smithing recipes, 75 Fletching recipes, 4 elemental battlestaff recipes, and (PASS31.40) 146 Herblore, 102 Crafting, 61 Cooking and 20 Runecrafting recipes generated by `data-pipeline/generate_skill_recipes.py`; see `docs/history/PASS31.40_SKILL_RECIPES_2026-11-08.md` for exclusions. Fletching coverage includes arrow shafts, bows, bow stringing, arrows, bolts, darts, crossbows, and flighted ogre arrows. The Smithing records cover the metal bars and products defined by `Bars.java`, `SmithingType.java`, and `BarType.java`, including Bronze equipment. Ragger is excluded.

The page supports search, skill filtering, character skill checks, bank-material checks, item links, and truthful unknown/incomplete recipe fields. Recipe item names are resolved through the shared `Catalog.list("items")` index, with `Catalog.get("items", id)` detail lookup as a fallback. Recipe loading normalizes singular/plural output fields and validates every input/output reference before rendering, so a catalog lookup failure is visible in the summary instead of silently dropping a recipe name.
