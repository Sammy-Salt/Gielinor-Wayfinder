# PASS31.74 – Progress page reorganised

Before: four stats, a summary bar, then 24 tall cards, each repeating a read-only "current level" box, a target box, a bar and two lines of XP text.
After:
- Summary: total level, total XP, quest points, targets met, one overall bar.
- "Closest to target": the three unmet skills with the least XP left, each linking to the Skill Calculator with the target filled in.
- Compact skill rows (two columns on desktop): skill name (links to the calculator), level, editable target, XP left, bar. Sort: game order, lowest level, closest to target, most XP remaining (choice remembered on this device).
- Refresh and reset buttons moved below the list, with links to Quest tracker and Goals. Emoji status dots and the redundant current-level inputs removed.
- No data or calculation changes.
