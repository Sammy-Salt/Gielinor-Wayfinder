# PASS31.80 – Icon spots move into the Show list

The invisible tap areas over the baked-in tile icons (PASS31.79) are removed, along with the shop tap popups. The same cache-derived spots now appear as categories in the "Show on map" list: Altar (chaos altars included), Anvil, Cooking range, Deposit box, Furnace, Loom, Potter's wheel, Pottery oven and Spinning wheel, each with a badge icon, a popup description and search by name. Banks stay under the existing Bank category. The drop-a-pin tool is unchanged.

Underground spots in a category are left off the surface map and counted in the status line, as for the other categories.
