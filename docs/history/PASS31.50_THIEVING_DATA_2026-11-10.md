# PASS31.50 — Thieving data (2026-11-10)

Adds `site/data/thieving.json` (42 rows), generated by `data-pipeline/generate_thieving.py` from 2009Scape commit 4082f9d with shape assertions (18 pickpockets, 18 stalls, 6 chests) and item-catalog validation.

- **Pickpockets** (`Pickpockets.kt`): level, xp, NPC ids, stun damage/ticks, success-chance inputs (`successLow`/`successHigh`, via `RandomFunction.getSkillSuccessChance`), and the full weighted loot table. Per `WeightBasedTable`, guaranteed rows always drop plus one weighted roll per success, so `chancePercent = weight / sum(weights) * 100`. Easy-clue rolls (Ham members) are modelled as `clue: "easy"` rows.
- **Stalls** (`Stall.java`): full/empty object ids, level, xp, respawn ticks, loot items. Quest-stall entries that are commented out in the source are not included.
- **Chests** (`ThievableChestPlugin.java`): object id, level, xp, respawn, contents.

Source quirks kept as-is: Desert bandit coins are `50,1` (min > max); `KNIGHT_OF_ADROUGNE` is displayed as "Knight of Ardougne"; the Master farmer table has no clue roll.

Not yet shipped: Thieving door lockpicking (`PickableDoorHandler.java`), stun/failure rules from `ThievingListeners.kt`, and any UI that reads this file.

Gate: `tests/test_pass31_50.py`.
