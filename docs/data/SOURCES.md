# Data Sources

## Precedence

**2009Scape → OSRS Wiki → unknown**

- 2009Scape implementation/catalog data is authoritative for this project.
- Wiki data is secondary evidence and may fill a missing field or relationship only when the identity is safely resolved.
- Conflicts are resolved in favor of 2009Scape.
- Ambiguous Wiki matches remain unresolved.
- No untrusted/retired third-party relationship source is part of the production pipeline.

Every generated relationship should retain its selected source and status so the UI and audits can explain why it exists.
