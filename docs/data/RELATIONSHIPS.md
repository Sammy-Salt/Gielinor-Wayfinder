# Relationships

Relationships are first-class data.

### Monster drops
`monsterId -> itemId` with optional quantity/rarity evidence.

### Shops
`shopId -> itemId` with shop/location/stock information when supplied by 2009Scape.

### Recipes
`materials -> output` with resolved endpoints and source provenance.

### Ground spawns
Ground-spawn information is shown only when a trusted source is available. Missing trusted ground-spawn data is reported as unknown rather than inferred.


## Monster-drop canonical dataset

`site/data/relationships/monster-drops.json` is the runtime canonical source for monster→item drop relationships and their probability provenance. It is generated by `data-pipeline/generate_drop_relationships.py`. The relationship graph supplies authoritative 2009Scape-derived endpoints; Wiki contributes only secondary exact probability evidence for an existing endpoint.
