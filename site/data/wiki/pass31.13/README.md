# PASS31.10 Wiki Reconciliation

PASS31.10 is a conservative reconciliation-triage pass built from PASS31.9.

## Scope
- Hardens classification of explicit Wiki page fragments and variant markers.
- Adds no new canonical entity mappings.
- Adds no new drop relationships.
- Adds no new recipe relationships.
- Uses no fuzzy matching.
- Preserves PASS31.9 canonical production data and existing verified relationships.

## Rules
See `triage-rules.json` for the exact rules and counts.

The purpose is to reduce the unresolved review queues before the next evidence-driven mapping pass, without promoting uncertain identities.
