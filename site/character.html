Game save

Pick your 2009Scape player .json save. The app remembers it and reloads character stats, bank, inventory, equipment and quests on open when the browser allows re-reading that file.

No local save linked yet.

Where is the save file?
  • Private server / desktop single-player: usually Server/data/players/<username>.json next to the 2009Scape server files.
  • Live / hosted play: the server keeps the save; you may need an export or admin copy of your .json.
  • Android mobile client: the save is inside the game app’s private storage. Copy it out with a file manager that can access app data, or use a desktop export, then pick that file here.

Chrome / Edge (and the TWA APK shell) can remember the file handle so the next open re-reads the same path after you grant permission once. Other browsers still keep the last imported snapshot until you pick again.
